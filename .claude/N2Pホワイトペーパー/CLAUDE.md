# CLAUDE.md — N2P ホワイトペーパー

## このプロジェクトの目的

NONAME Produce（n2p）のインターン業務における、ホワイトペーパー（WP）作成の質と効率を上げること。

## 課題感

- WP の構成を作る際に、つくる人やAIによって品質・構成がその都度バラつく
- 構成がブレると後続のスライド作成もブレるため、構成段階での品質担保が必要
- WP 構成 → スライド変換のプロセスが定型化されておらず、毎回手作業になっている。人の作業をできるだけ少なくする。

## 目標

1. **WP 構成作成の Skill 化**  
   AI と対話しながら一定のクオリティで WP の構成を出せる Skill を作る。構成力を Skill に持たせることで、後続のスライド作成がブレないようにする。

2. **WP 構成からスライドへの変換の Skill 化**  
   WP の構成が完成したら、それをもとに規定フォーマットでスライド化できるようにする。作成時のブレをなくすため Skill として定型化する。
