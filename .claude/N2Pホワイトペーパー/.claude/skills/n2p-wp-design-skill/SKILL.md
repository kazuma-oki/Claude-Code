# n2p WP スライド作成スキル

## このスキルの目的

n2p-wp-writing skillで作成したWP構成Markdown（`*-wp-structure.md`）を汎用スクリプト `generate_slides.py` に渡し、n2pのデザインルールに従ったPowerPointスライド（.pptx）を自動生成する。

**AIがPythonを書く必要はない。** Markdownを渡してスクリプトを実行するだけでよい。

---

## 進め方の全体像

1. **テーマカラーの確認**（ユーザーに尋ねる → コントラスト比チェック）
2. **WP構成ファイルの確認**（どのMarkdownを使うか確認）
3. **スクリプトの実行**（`generate_slides.py` にMarkdownパスとアクセントカラーを渡す）
4. **報告**（生成枚数・保存先・スキップ情報をユーザーに伝える）

---

## フェーズ1：テーマカラーの確認とコントラストチェック

ユーザーにアクセントカラー（テーマカラー）のHEXコードを尋ねる。

得られたカラーを使って以下の2パターンのコントラスト比を計算する：
- **白背景（#FCFCFC）× アクセントカラー文字**：WCAG AA基準 = 4.5:1以上
- **アクセントカラー背景 × 白文字（#FCFCFC）**：同じく4.5:1以上

基準を下回る場合はユーザーに警告し、明度調整案を提示する。了承が取れたら次へ進む。

コントラスト比の算出：
```
相対輝度 L = 0.2126·R + 0.7152·G + 0.0722·B
  （各成分はsRGBを線形化：c≤0.04045 → c/12.92、c>0.04045 → ((c+0.055)/1.055)^2.4）
コントラスト比 = (L_lighter + 0.05) / (L_darker + 0.05)
```

## フェーズ2：WP構成ファイルの確認

どのWP構成ファイル（`*-wp-structure.md`）を使うかをユーザーに確認する。
ファイルを読み込み、章数・ページ数・事例の有無・差し込み章の有無を把握する。

---

## フェーズ3：スクリプトの実行

汎用スクリプト `generate_slides.py` にMarkdownのパスとアクセントカラーを渡して実行する。

### コマンド

```
python "C:\Users\kazug\.claude\N2Pホワイトペーパー\.claude\skills\n2p-wp-design skill\generate_slides.py" "<*-wp-structure.mdのフルパス>" <ACCENT_HEX>
```

- `ACCENT_HEX`：アクセントカラーのHEXコード（`#` なしで指定、例：`1665F2`）
- 省略した場合はデフォルトの `1665F2`（BCFF ブルー）が使われる

### 実行例

```
python "C:\Users\kazug\.claude\N2Pホワイトペーパー\.claude\skills\n2p-wp-design skill\generate_slides.py" "C:\Users\kazug\.claude\N2Pホワイトペーパー\BCFF WP\BCFF-wp-structure.md" 1665F2
```

### スクリプトが自動で行うこと

1. Markdownをパースしてスライドタイプを判定
2. 表紙・目次・章題・一般・事例の各ページを順番に生成
3. 「〇〇のご案内」「その他のご案内」章にPowerPoint COMで差し込みPPTXを挿入
4. Markdownと同じフォルダに `{プロジェクト名}-slides.pptx` として保存

### 出力ファイル名のルール

Markdownのファイル名から `-wp-structure.md` を取り除いたものがプロジェクト名になる。

- `BCFF-wp-structure.md` → `BCFF-slides.pptx`
- `X-algorithm-wp-structure.md` → `X-algorithm-slides.pptx`

## 参考：MarkdownフォーマットとスライドタイプEの対応

スクリプトは以下のルールでMarkdownを解釈する。

| Markdownの要素 | 生成するスライド | 枚数 |
|---|---|---|
| （先頭、自動） | 表紙ページ（白紙） | 1 |
| （全章から自動生成） | 目次ページ | 1 |
| `## 第N章：〇〇`（サービス紹介・その他ご案内以外） | 章題ページ | 1 |
| `### N-M：〇〇`（`- フロー：` なし） | 一般ページ | 1 |
| `### N-M：〇〇`（`- フロー：` あり） | 事例ページ 1枚目 ＋ 2枚目 | 2 |
| `## 第N章：〇〇のご案内` | 章題ページ ＋ 差し込みPPTX | 1+ |
| `## 第N章：その他のご案内` | 章題ページ ＋ 差し込みPPTX | 1+ |

**事例ページの判定**：`- フロー：` フィールドがあれば事例ページ（2スライド）として処理する。

**実績表の生成**：事例ページに `- 実績：` フィールドがある場合、2枚目スライドの右側に実績データ表を自動生成する。

`- 実績：` フィールドの書式：`アクション名:数値 / アクション名:数値 / ...`
例：`いいね:1049984 / リポスト:301031 / ハッシュタグ投稿:47640`

**差し込みファイルの解決ルール**：
- `その他のご案内` → `inserts/n2p-wp-other.pptx`
- その他の「〇〇のご案内」→ `inserts/` 内の `n2p-wp-other.pptx` 以外の最初の `.pptx` ファイル
- ファイルが存在しない場合は章題ページのみ生成し、スキップを報告

**差し込みPPTXの統合**：python-pptxではなくPowerPoint COMの `InsertFromFile()` を使う（テーマ・フォント・カラーを保持するため）。

各スライドタイプの詳細な寸法・配置・フォント仕様は **`references/slide-specs.md`** を参照すること。

---

## 注意事項

- **グラデーション禁止**：グラデーションカラーは一切使わない
- **ラインマーカーは最小限**：1スライドあたり最大2〜3箇所。他の文面をシンプルに保つことで強調が際立つ
- **差し色禁止**：強調はラインマーカーまたはボールドのみ。赤・青などの差し色は使わない
- **純白使用禁止**：白は #FFFFFF ではなく必ず #FCFCFC を使う
- **コントラスト優先**：コントラスト比 4.5:1 未満の色の組み合わせは使わない
