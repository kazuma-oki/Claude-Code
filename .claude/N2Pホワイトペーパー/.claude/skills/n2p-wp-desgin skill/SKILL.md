# n2p WP スライド作成スキル

## このスキルの目的

n2p-wp-writing skillで作成したWP構成Markdown（`*-wp-structure.md`）を読み込み、n2pのデザインルールに従ったPowerPointスライド（.pptx）をpython-pptxで自動生成する。

---

## 進め方の全体像

1. **テーマカラーの確認**（ユーザーに尋ねる → コントラスト比チェック）
2. **WP構成ファイルの確認**
3. **Markdownのパース**（スライドタイプの判定）
4. **PPTXの生成**（python-pptxでスライドを順番に作成）
5. **差し込みページの処理**
6. **保存・報告**

---

## フェーズ1：テーマカラーの確認とコントラストチェック

ユーザーにアクセントカラー（テーマカラー）のHEXコードを尋ねる。

得られたカラーを使って以下の2パターンのコントラスト比を計算する：
- **白背景（#FCFCFC）× アクセントカラー文字**：WCAG AA基準 = 4.5:1以上
- **アクセントカラー背景 × 白文字（#FCFCFC）**：同じく4.5:1以上

基準を下回る場合はユーザーに警告し、明度調整案を提示する。了承が取れたら次へ進む。

コントラスト比の算出：
```
相対輝度 L = 0.2126·R + 0.7152·G + 0.0722·B
  （各成分はsRGBを線形化：c≤0.04045 → c/12.92、c>0.04045 → ((c+0.055)/1.055)^2.4）
コントラスト比 = (L_lighter + 0.05) / (L_darker + 0.05)
```

## フェーズ3：Markdownパースとスライドタイプの判定

WP構成Markdownを以下のルールでスライドタイプに変換する。ページ番号は表紙を p.1 として連番でカウントする。

| Markdownの要素 | 生成するスライド | 枚数 |
|---|---|---|
| （先頭、自動） | 表紙ページ（現状白紙） | 1 |
| （全章から自動生成） | 目次ページ | 1 |
| `## 第N章：〇〇`（サービス紹介・その他ご案内以外） | 章題ページ | 1 |
| `### N-M：〇〇`（`- フロー：` なし） | 一般ページ | 1 |
| `### N-M：〇〇`（`- フロー：` あり） | 事例ページ 1枚目 ＋ 2枚目 | 2 |
| `## 第N章：〇〇のご案内` | 章題ページ ＋ 差し込みPPTX | 1+ |
| `## 第N章：その他のご案内` | 章題ページ ＋ 差し込みPPTX | 1+ |

**事例ページの判定**：`- フロー：` フィールドがあれば事例ページ（2スライド）として処理する。

**目次の生成**：`## 第N章` のタイトルをすべて収集し、目次ページに使う。
- `## 第1章：なぜ…` → `01.なぜ…`
- `## 第2章：発話を…` → `02.発話を…`
- `## 第N章：まとめ` → `0N.まとめ`
- `## 第N章：BirdCall for Funのご案内` → `0N.BirdCall for Funのご案内`
- `## 第N章：その他のご案内` → `0N.その他のご案内`

## フェーズ4：PPTXの生成

python-pptxを使ってPythonスクリプトを書き、実行する。

### 基本設定

```python
from pptx import Presentation
from pptx.util import Cm, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

prs = Presentation()
prs.slide_width  = Cm(25.4)
prs.slide_height = Cm(14.29)
```

### カラー定数

```python
BASE   = RGBColor(0xFC, 0xFC, 0xFC)  # #FCFCFC ベース（白）
MAIN1  = RGBColor(0x11, 0x11, 0x11)  # #111111 メインカラー1（見出し黒）
MAIN2  = RGBColor(0x43, 0x43, 0x43)  # #434343 メインカラー2（本文グレー）
ACCENT = RGBColor(r, g, b)           # ユーザー指定のアクセントカラー
LINE   = RGBColor(0xE6, 0xEB, 0xED)  # #E6EBED 下線・区切り
CR     = RGBColor(0x92, 0x96, 0x99)  # #929699 ©表記・ページ番号
BAR    = RGBColor(0x93, 0x96, 0x99)  # #939699 一般ページ左細棒
YELLOW = RGBColor(0xF4, 0xF4, 0x00)  # #F4F400 ラインマーカー
```

## フェーズ5：差し込みページの処理

`INSERT_DIR` を確認し、以下のルールで差し込む：

- `## 第N章：〇〇のご案内` → サービス名から `n2p-wp-(サービス名).pptx` を探す
  - 例：「BirdCall for Funのご案内」 → `n2p-wp-BCFF.pptx`
- `## 第N章：その他のご案内` → `n2p-wp-その他ご案内.pptx` を差し込む
- 対応ファイルが存在しない場合：章題ページのみ生成し、スキップを報告する

差し込みPPTXの統合には、python-pptxでソースPPTXのスライドXMLを取り出して追加する方式を使う。

---

## フェーズ6：ファイル保存と報告

- **ファイル名**：`{プロジェクト名}-slides.pptx`（例：`BCFF-slides.pptx`）
- **保存場所**：WP構成Markdownと同じフォルダ

保存後、以下をユーザーに報告する：
1. 生成されたスライド総枚数
2. ファイルの保存先パス
3. 差し込みPPTXがなかったためスキップした章
4. その他確認事項（ラインマーカー使用箇所など）

---

## 注意事項

- **グラデーション禁止**：グラデーションカラーは一切使わない
- **ラインマーカーは最小限**：「このページの主張は何か？」「その主張を支える最重要情報は何か？」を自問し、1スライドに多用しない。他の文面をシンプルに保つことで強調が際立つ
- **差し色禁止**：強調はラインマーカーまたはボールドのみ。赤・青などの差し色は使わない
- **純白使用禁止**：白は #FFFFFF ではなく必ず #FCFCFC を使う
- **コントラスト優先**：コントラスト比 4.5:1 未満の色の組み合わせは使わない
