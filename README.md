# Claudeとは？

- エージェント型AIの1つ

## Claude ≠ Claude Code

| 項目 | 内容 |
|---|---|
| Claude | AIそのもの |
| Claude Code | Claudeを動かすツール |

---

# 4つの使い方

1. CLI
2. VSコード
   - ファイル操作・分析しやすい！
3. デスクトップアプリ
4. ブラウザ

---

# 簡単な流れ

1. VSコードをインストール
2. 拡張機能「Claude Code」を導入
3. ファイル → 作業したいファイルを選択
4. `CLAUDE.md` を作成
   - 最初は10行くらいでOK
   - 上限は200行目安

---

# CLAUDE.md の書き方

- 役割（私の）
- 目標
- 制約

→ 自己紹介みたいなもの・心得

## 補足

- 自分で作成してもいい
- `/init` で自動的につくれる

# Skills.md について

- 必要なものだけマニュアルを選択し、トークン使用量・処理量を減少させる
- AIに特定の手順を踏んでもらう専用アシスタント
- Skillの内容によって出力品質が変化する
- Skillsは成長させていくのが肝

---

# Skill の呼び出し方

- AIによるSkillの自動選択
  - ただし、どれを使うかはAI次第
- `/（コマンド）` による呼び出し

---

# Skill の仕組み

## フォルダ構成

```txt
user/.claude/skills/(スキル名のフォルダ)/SKILL.md
```

## SKILL.md の基本構成
https://agentskills.io/specification
```md
---
name: （フォルダ名）
description: （このスキルが何をするのか？）
version:
---

本文（具体的な手順）
```

---

# Skills.md の書き方

- フォーマットは「Agent Skills」
- Anthropic が公開しているものもある
- Skillsを書くSkillsも存在する
- Skillsは成長させていくのが肝

---

# フォルダ構成

```txt
ホームフォルダ（ユーザー名）
│
├── .claude/
│   ├── CLAUDE.md
│   │   └── 全フォルダ共通（グローバル）
│   └── Skills/
│       └── スキル名のフォルダ
│           └── SKILL.md
│
└── my-project（作業フォルダ）
    ├── CLAUDE.md
    │   └── このプロジェクト内のみ適用(プロジェクト配下に置くのが推奨されている）
    └── .claude/
        └── Skills/
            └── スキル名のフォルダ
                └── SKILL.md
```
